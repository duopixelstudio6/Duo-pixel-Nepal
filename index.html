App Development Service Models

MODEL A

APK / App Only

Perfect for clients who know how to manage app distribution or want to test/sideload their Android application.

What Duo Pixel Provides:
  • Complete app design & development
  • Final compiled .APK file download link
  • App installation verification testing
Client Responsibility:
  • • Google Play Console account registration ($25 fee paid to Google)
  • • Manual APK distribution or hosting on third-party sites
MODEL B (ASSISTED)

Complete App Package

Ideal if you need guidance preparing app assets, store screenshots, and submission-ready files.

What Duo Pixel Provides:
  • Full app development & compiled APK/AAB
  • App icon assets & Play Store preview screenshots
  • Store listing text & privacy policy template
Client Responsibility:
  • • Google Play Developer Account fees (paid directly to Google)
  • • Final account log-in and button click for Play Store submission

Website Development Service Models

MODEL A

Website Files Only

For tech-savvy clients or developers who already own hosting/domain and want clean website code.

What Duo Pixel Provides:
  • Complete custom website design & code
  • Clean HTML/CSS/JS or project source ZIP
  • Local preview file and basic instructions
Client Responsibility:
  • • Domain name purchase (.com, .np, etc.)
  • • Hosting server account and uploading files
MODEL B (LAUNCH ASSIST)

Website + Launch Package

Complete service where we build your site and connect it to your domain or free web host (Netlify/Vercel/GitHub Pages).

What Duo Pixel Provides:
  • Full website design & development
  • Free hosting deployment setup (Vercel/Netlify/Cloudflare)
  • Domain DNS connection assistance
Note On Domain/Hosting Costs:
  • • Domain renewal fees are paid by client to the registrar.
  • • Free hosting setup applies to static site limits (plenty for most small sites).
